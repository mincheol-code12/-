# eCommerce CRM 최적화 — 퍼널 분석부터 인과추론 검증까지

## 프로젝트 개요

eCommerce 플랫폼(Kaggle) 데이터를 활용해 퍼널 구간별 이탈 원인을 통계적으로 검증하고, ML 기반 CRM 타겟 최적화로 이어지는 분석 프로젝트입니다.

- **분석 대상**: 3,980,480명 / 2개월 (2019년 10~11월)
- **데이터 출처**: [eCommerce behavior data from multi category store (Kaggle)](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store)
- **KPI 대시보드**: (https://public.tableau.com/app/profile/mincheol.ko/viz/_17795123471130/1#1)

## 분석 흐름

```
DA: 퍼널 이탈 분석
├── View → Cart     : apparel 카테고리 전환율 6.0% (전체 평균 13.3%)
├── Cart → Purchase : 세션 이탈 유저 14.3%가 나중에 동일 상품 구매 (지연 전환)
└── Purchase → Repurchase : cart 재추가 행동이 재구매의 가장 강력한 선행 지표 (V=0.505)
        ↓
DS: 규칙기반 CRM의 한계 → ML 타겟 최적화
└── Combined Score(재구매 확률 × 구매 가치) 기반 Top 50% 타겟팅
    → 발송 수 22.5% 감소, Value Recall 81.8% 유지
        ↓
인과추론: 핵심 신호(cart 재추가)는 상관관계인가, 인과관계인가?
└── DoWhy(PSM/IPW) + Refutation(Placebo, Data Subset, Unobserved Confounder)
    → 성향 차이(가격대·구매 신중도) 통제 후에도 효과 유지 (45%p대)
    → CRM 개입("재입고 알림·리마인더") 설계 근거 확보
```

## 1. 문제 정의

| 단계 | 고객 수 | 이탈률 |
|---|---:|---:|
| View | 3,980,480명 | — |
| Cart | 810,407명 | 79.6% |
| Purchase | 517,878명 | 36.1% |
| 재구매 | 204,865명 | 60.5% |

퍼널 규모는 고유 유저 기준이며, 구간별 이탈 분석은 목적에 따라 기준이 다릅니다.

| 구간 | 분석 기준 | 이유 |
|---|---|---|
| View→Cart | 세션 | 카테고리별 전환율 = 세션 내 view → cart 발생 여부 |
| Cart→Purchase (이탈 정의) | 세션 | 같은 세션 내 cart 후 purchase 없이 종료 |
| Cart→Purchase (지연 전환) | 유저×상품 | 세션을 넘어 동일 유저가 동일 상품을 나중에 구매 |
| Purchase→Repurchase | 유저 | 동일 유저의 두 번째 구매 여부 |

데이터를 구간별로 쪼개보니 각 구간에서 이탈 유저의 특성이 달랐습니다. 특성이 다르면 개입 방식도 달라야 합니다.

**분석 목표**: 퍼널 전환 실패 원인을 통계적으로 검증하고, 구간별로 다른 개입 전략을 도출한다.

**채택 기준**: `p < 0.05` AND 효과크기 동시 충족 (범주형 — Cramér's V ≥ 0.1 / 연속형 — rank-biserial |r| ≥ 0.1). 수백만 건 데이터에서는 p-value만으로 사소한 차이도 유의미하게 나오기 때문에 효과크기를 병행 기준으로 뒀습니다.

## 3. 분석 — View→Cart

### "유저가 어떻게 탐색하느냐보다 무엇을 보느냐가 결정했다"

apparel의 View→Cart 전환율이 6.0%로 전체 평균(13.3%)의 절반 이하였습니다. 같은 플랫폼 안에서 카테고리 간 3.4배 차이가 났습니다.

| 카테고리 | View→Cart 전환율 |
|---|---:|
| electronics | 20.5% |
| appliances | 15.2% |
| computers | 11.6% |
| **apparel** | **6.0%** |
| 전체 평균 | 13.3% |

이 결과가 나오기까지 반복 조회, 카테고리 대비 가격 장벽, 첫 방문 vs 재방문 세 가설을 먼저 검증했지만 모두 효과크기 기준 미달(r = 0.063~0.084)이었습니다. 유저의 탐색 방식이 아닌 **카테고리의 구조적 특성**이 유일한 유효 신호였습니다(V = 0.113).

electronics는 목적성 탐색이 강해 가격 비교 목적으로 장바구니를 적극 활용하는 반면, apparel은 사이즈·핏의 불확실성과 트렌드 탐색 목적의 브라우징 비중이 높아 구매 의도 없이 세션이 종료되는 경우가 많은 것으로 해석했습니다.

**액션**: apparel 상품 페이지 UI/UX 개선 — 사이즈 가이드·실측 정보 강화, 다양한 체형 모델 착용 이미지 제공

## 4. 분석 — Cart→Purchase

### "세션 이탈은 비즈니스 이탈이 아니었다"

세션 기준 전환 실패한 유저 중 **14.4%는 나중에 동일 상품을 구매**했습니다. 세션이 끝났다고 고객을 잃은 게 아니라, 그 세션에서 결제로 이어지지 않은 **지연 전환자**였습니다.

이 발견에 앞서 고가 상품 장벽, 장바구니 복잡도, cart 전후 탐색 패턴, 첫 방문 여부 네 가설을 검증했지만 모두 효과크기 기준 미달(r = 0.007~0.096)이었습니다. 세션 내 행동만으로는 전환 실패를 설명할 수 없었습니다.

14.4%가 나중에 구매했다는 건 cart 이탈자에게 여전히 구매 의도가 있다는 뜻이므로, 행동 패턴으로 유형을 나눠 CRM을 다르게 설계했습니다.

| 유형 | 정의 | 비율 |
|---|---|---:|
| 유형 A (비교형) | cart 후 추가 탐색 있음 | 40% |
| 유형 B (임시저장형) | cart 후 세션 바로 종료 | 59% |

**액션**
- cart 이탈 유저 전체 → 이탈 직후 동일 상품 리마인드 CRM (유형 B 우선)
- apparel cart 이탈 → 사이즈 가이드·반품 보장 포함 CRM

## 5. 분석 — Purchase→Repurchase

### "접점의 깊이가 재구매를 결정했다"

관측 기간 한계로 재구매 소요일 Q3(18일) 이상 관측 가능한 유저(332,125명)만 분석 대상으로 제한했습니다 (N=18일 기준 재구매율 35.5%).

| 가설 | 결과 | 효과크기 | 채택 |
|---|---|---:|:---:|
| 첫 구매 후 view 이벤트 여부 | view 없음 0.7% vs view 있음 41.4% | V = 0.300 | ✅ |
| 재방문 후 cart 재추가 여부 | cart 없음 23.8% vs cart 있음 75.1% | **V = 0.495** | ✅ |
| 이탈자 vs 재구매자 첫 구매금액 차이 | 이탈자 $314.7 vs 재구매자 $376.6 (-$61.9) | r = -0.112 | ✅ |

V=0.495는 이 프로젝트 전체 최고 효과크기입니다. view 여부와 cart 재추가 여부를 기준으로, 첫 구매 이후 유저를 3단계로 세분화했습니다.

| 세그먼트 | 행동 | 인원 | 재구매율 |
|---|---|---:|---:|
| 1단계 | 첫 구매 후 view 없음 | 47,988명 | 0.7% |
| 2단계 | view는 있지만 cart 재추가 없음 | 141,957명 | 23.8% |
| 3단계 | cart 재추가까지 한 유저 | 24,312명 | 75.1% |

**액션 — 3단계 세그먼트 CRM**
- 1단계: 첫 구매 후 7일 미접속 → 관련 상품·구매 리뷰 알림
- 2단계: 탐색량 2배 증가 패턴 기반 개인화 큐레이션 발송
- 3단계: 담아둔 상품 한정 할인·재고 소진 알림

다만 이 규칙기반 CRM은 개별 재구매 확률과 구매 가치를 고려하지 못한다는 한계가 있었고, 이는 Part 2로 이어집니다.

## 6. 분석 — 재구매 예측 모델 & CRM 타겟 최적화 (Part 2)

### 6-1. 문제 정의

Part 1에서 도출한 이탈 위험군 214,188명에게 일괄 CRM을 발송하는 규칙기반은 재구매 확률과 구매 가치를 고려하지 않습니다. "이탈 확률 상위 N% AND 구매금액 상위 N%" 방식의 규칙 정교화도 시도했지만, 이탈 확률과 구매금액이 반비례 관계라 두 조건을 동시에 충족하는 유저가 극히 적어 규칙으로는 구조적으로 불가능했습니다.

**목표**: 발송 수를 줄이면서 이탈자 가치의 최대한을 포착하는 타겟을 ML로 선정한다.

### 6-2. 모델링

3개 모델(Logistic Regression, Random Forest, XGBoost)을 비교했습니다. 발송 비용 절감이 목적이므로 단순 정확도 대신 **Precision(낭비 발송 감소)**을 핵심 지표로 삼았습니다.

| 지표 | LR | RF | XGBoost |
|---|---:|---:|---:|
| Precision (미재구매 클래스) | 0.69 | **0.72** | 0.69 |
| Recall (미재구매 클래스) | 0.96 | **0.77** | 0.96 |

RF가 Precision 최고(0.72)이며 Recall이 상대적으로 낮아(0.77) 더 적게, 더 정확하게 타겟팅합니다. 발송수 절감 목적과 가장 일치해 RF를 최종 모델로 선택했습니다.

### 6-3. Combined Score 기반 CRM 타겟 최적화

CRM Score(이탈 확률)만으로 정렬하면 구매금액이 낮은 이탈자가 우선 타겟이 되는 문제가 있었습니다. crm_score와 첫 구매금액의 상관관계는 **r = -0.31**(약한~중간 수준의 음의 상관관계)로, 이탈 위험이 높을수록 구매금액이 낮은 경향이 확인됐습니다.

→ **Combined Score = CRM Score × first_purchase_price**로 이탈 위험도와 구매 가치를 결합해 재정렬했습니다.

| 지표 | 규칙기반 | ML Top 50% | 개선 |
|---|---:|---:|---:|
| 발송 수 | 214,188명 | **166,062명** | **-22.5% (-48,126명)** |
| Value Recall | 100% | **81.8%** | -18.2%p |
| 발송 효율 | $314.8/send | **$332.3/send** | **+5.6% (1.06x)** |

Top 50%를 선택한 이유는, 이 지점까지는 발송 1건당 포착 가치가 규칙기반보다 높고(효율배수 1.06x), Top 60%부터는 효율이 역전(0.94x)되기 때문입니다.

발송 수를 22.5% 줄이면서 이탈자 가치의 81.8%를 유지합니다.

### 6-4. 쿠폰율 손익분기 분석

이탈 유저는 재구매 유저보다 평균 구매금액이 $61.9 낮아 CRM만으로는 전환 동기가 부족할 수 있어, 쿠폰 인센티브를 함께 고려했습니다. 전환율 3% 가정 하에 쿠폰율별 순이익을 시뮬레이션했습니다.

| 쿠폰율 | 규칙기반 순이익 | ML Top 50% 순이익 | 차이 |
|---:|---:|---:|---:|
| 1.0% | +$1.349M | +$1.132M | -$0.217M |
| **2.4%** | +$0.405M | +$0.400M | **← 손익분기점** |
| 3.0% | +$0.001M | +$0.087M | +$0.086M |
| 5.0% | -$1.347M | -$0.958M | +$0.389M |
| 20.0% | -$11.458M | -$8.797M | +$2.661M |

**결론**: 쿠폰율 2.4% 이상이면 어떤 쿠폰율에서도 ML Top 50%가 규칙기반보다 순이익이 높습니다. 쿠폰율이 높아질수록 두 전략의 격차도 커집니다(쿠폰 20%에서 ML이 $2.66M 덜 손실).

> 위 수치는 전환율 3% 고정, 회수 가치 = 첫 구매금액 가정 기준입니다. 가정이 달라지면 절대 수치는 달라지지만 두 전략의 상대적 우위는 유지됩니다.

## 7. 분석 — 인과추론: 상관관계인가 인과관계인가 (Part 3)

### 7-1. 문제의식

Part 1과 Part 2 모두에서 "첫 구매 후 장바구니 재추가 여부"가 재구매와 가장 강하게 연관됐습니다(V=0.495, LR 계수 1위). 하지만 이는 상관관계입니다. "장바구니 재추가한 사람이 재구매를 잘 한다"와 "장바구니 재추가가 재구매를 만든다"는 다른 얘기입니다. "원래 구매 의향이 높은 사람"이라는 공통 원인(교란) 때문에 두 행동이 함께 나타나는 것이라면, CRM으로 재추가를 유도해도 재구매는 늘지 않습니다.

**목표**: 장바구니 재추가(T)가 재구매(Y)에 미치는 순수 인과효과(ATE)를 DoWhy로 추정하고 강건성을 검증한다.

### 7-2. Covariate Balance Check

재구매율이 재추가 안 한 집단은 31.2%(재구매율 기준 비교 시 raw 차이 44.3%p)로, 재추가한 집단과 큰 차이가 났습니다. 그런데 두 집단은 애초에 성향이 달랐습니다.

| 비교 항목 | 재추가 안 함 | 재추가 함 |
|---|---:|---:|
| 첫 구매까지 걸린 시간 | 4.4일 | 6.0일 |
| 구매 전 장바구니 사용 횟수 | 1.2회 | 1.6회 |
| 첫 구매 가격 | $333 | $370 |

재추가한 집단은 더 신중하게, 더 비싼 물건을 사는 경향이 뚜렷했습니다 — 두 집단이 원래 다른 성향의 사람들일 가능성(교란)이 확인되어, 이를 통제하는 절차로 이어갔습니다.

### 7-3. DoWhy 기반 ATE 추정 및 검증

DAG을 명시하고(Model) → 교란 변수를 Backdoor Criterion으로 식별하고(Identify) → PSM/IPW로 성향 차이를 통제한 뒤(Estimate) 재구매율 차이를 다시 계산했습니다.

| 구분 | 재구매율 차이 | 비고 |
|---|---:|---|
| 통제 전 (raw) | 44.3%p | 성향 차이 미보정 |
| PSM 추정치 | **45.7%p** | 95% CI: 45.1~46.5%p |
| IPW 추정치 | 45.2%p | PSM과 교차검증 |

교란요인을 통제해도 효과가 줄지 않았습니다 — 오히려 raw보다 약간 커졌습니다. 계산 원리가 다른 두 기법(PSM, IPW)이 비슷한 값으로 수렴한 것도 특정 기법의 우연이 아니라는 근거입니다.

**Refutation Test로 신호 검증**

| 검증 | 결과 | 판정 |
|---|---|:---:|
| Placebo Treatment Test | New effect ≈ 0 (p=0.92) | 통과 |
| Data Subset Refuter | 0.456 (원래값 0.4566과 유사, p=0.88) | 통과 |
| Unobserved Confounder 민감도 | 5% 세기 가정 시 45.7%p→25.8%p | 방향 유지, 크기는 민감 |

가짜 처치로 재분석한 결과 효과가 사실상 0(p=0.92)으로 나와, 방법론이 노이즈를 정확히 걸러냈다는 근거가 됩니다. 80%만 무작위 추출해 재추정해도 원래 값과 유사하게 재현되어, 특정 표본에 국한된 결과가 아님을 확인했습니다.

### 7-4. 결론 및 한계

장바구니 재추가는 재구매와 인과적으로 연결된 요인일 가능성이 높습니다. 가격대·구매 신중도 같은 관측된 성향 차이를 걷어내도 효과가 45%p대로 유지됐습니다.

전환율 3%를 가정한 Part 2 ML 순이익 역전 기점과 비교하면, 45%p는 그보다 훨씬 큰 잠재력입니다 — 재입고 알림·장바구니 리마인더 같은 CRM 콘텐츠에 우선순위를 둘 근거가 됩니다.

다만 민감도 분석 결과, 약한 세기(5%)의 관측되지 않은 교란요인만 가정해도 추정치가 45.7%p → 25.8%p로 하락했습니다. CRM이 실제로 재추가를 유도했을 때도 같은 효과가 날지는 A/B 테스트로 별도 검증이 필요합니다.
